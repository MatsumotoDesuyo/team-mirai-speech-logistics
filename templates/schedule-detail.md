# スケジュール検討シート テンプレート規約

衆 26 スケジュール検討シートのレビューを踏まえ、ブラッシュアップを加えたテンプレートを定義する。1 日 1 タブの構造は衆 26 で実運用された実績があるため維持。

## 設計原則

1. **1 日 1 タブ**: 衆 26 で機能した構造を維持。タイムライン視覚化の利点を活かす。
2. **spot-base 集約**: 演説場所詳細は spot-base に登録された URL を貼るだけで完結する形を理想とする。spot-base に無い場合のみシート側に直接記入。
3. **タスク種別の enum 化**: 「街頭演説」「移動」「休憩」を機械可読にし、AI 抽出の信頼性を上げる。
4. **LINE オプチャ連携を含む**: 「想定参加サポーター数」「場所取り担当」列で、当日朝の人員判断を支援。

## タブ命名規約

| パターン | 用途 | 例 |
|---|---|---|
| `YYYY-MM-DD_候補者名` | 日別スケジュール（メイン）| `2027-04-18_山田太郎` |
| `_候補リスト_<エリア>` | エリア別場所候補（補助）| `_候補リスト_東京18区` |
| `_過去実績` | 過去演説の振り返り（補助）| - |
| `_メモ` | 自由メモ（補助）| - |

- 日別タブはタブ名昇順で時系列に並ぶ。
- 補助タブは `_` prefix で日別タブと区別。

## 日別タブの構造

### A1〜B3: タブメタデータ

| セル | 内容 | 例 |
|---|---|---|
| A1 | 司令塔シート該当行 URL | https://docs.google.com/spreadsheets/d/.../edit#gid=...&range=A18 |
| B1 | 演説日 | 2027-04-18 |
| A2 | 演説エリア | 東京都〇〇区 |
| B2 | 想定マイク納め時刻 | 18:30 |
| A3 | 担当 | 演説決め隊メンバー名 |

### Row 5 以降: タイムラインテーブル

| 列 | 名前 | 意味 | 入力規約 |
|---|---|---|---|
| A | 開始時刻 | スロット開始 | `HH:MM` |
| B | 終了時刻 | スロット終了 | `HH:MM` |
| C | 所要時間(min) | 所要分数 | 数式または整数 |
| D | **種別** | タスク種別 | **enum: 演説 / 移動 / 休憩 / マイク納め / 場所取り / その他** |
| E | タスク名 | 自由テキスト名 | 例: 「街頭演説 渋谷ハチ公前」 |
| F | 演説場所 | 場所の名称 | 例: 「渋谷ハチ公前」 |
| G | **spot-base URL** | spot-base 登録 URL | 登録済みの場合のみ。URL があれば H 〜 K は空欄可 |
| H | 演説場所写真 | Google Drive URL | spot-base が無い場合のみ記入 |
| I | 演説場所補足 | テキスト説明 | 同上 |
| J | 演説場所 GoogleMap | Maps URL | 同上 |
| K | 演説場所住所 | テキスト住所 | 同上 |
| L | **想定参加** | LINE オプチャアンケート結果（参加表明数）| 数値 |
| M | **場所取り担当** | 場所取り担当者名 | テキスト |
| N | 参考URL | 任意の参考リンク | 自由 |
| O | 備考 | 特記事項 | 自由テキスト |

## spot-base URL を最優先する運用

> 演説場所詳細は spot-base URL を貼れればそれが一番。無い場合のみ写真・補足・Map・住所を直接記入。

優先順位:

1. **G 列に spot-base URL がある** → H〜K は空欄でも可。詳細は spot-base 側参照
2. **spot-base に該当スポット無し** → H〜K に直接記入、後で spot-base 登録（次回からは URL のみで済む）

これにより、スケジュール検討シートは spot-base の「補完バッファ」として機能。スポット情報の蓄積は spot-base に集約される。

## 衆 26 からの主な差分

| 衆 26 | 今期テンプレ | 理由 |
|---|---|---|
| タスク名のみ（自由テキスト） | D 列 「種別」を enum 追加 | AI 抽出の信頼性向上 |
| 場所詳細をシートに直接記入 | G 列 「spot-base URL」優先 | 二重管理排除、spot-base 集約 |
| タブ名規約なし | `YYYY-MM-DD_候補者名` / `_` prefix 規約 | 23 タブ規模の可読性 |
| 人員情報なし | L 列「想定参加」、M 列「場所取り担当」 | LINE オプチャ連携、人員判断 |
| 司令塔シートとの参照リンクなし | A1 セルに司令塔該当行リンク | 人間ナビゲーション補助 |
| 補助タブと日別タブ混在 | 補助タブは `_` prefix で分離 | タブ一覧の視認性 |
