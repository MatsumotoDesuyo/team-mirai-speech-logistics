## 発見した問題と対応

### 問題 1: LINE オプチャアンケート選択肢が MANUAL.md §10.3.2 と異なる

| | 内容 |
|---|---|
| 期待 | 「手伝いに行きます！/行けたら行きます！/気持ちだけ応援！/場所取りします！」の 4 選択肢 |
| Gemini Flash 出力 | 「参加可能な時間帯」「希望担当業務」のフォーム形式 |
| 原因 | chief-of-staff プロンプトの「主要参照箇所」リストに §10.3 が含まれず、「告知文作成」スキルに §10.3.2 の 4 選択肢使用指示がなかった |
| 対応 | **修正実施**: プロンプトと MANUAL.md §14.5 に §10.3 参照と 4 選択肢使用指示を追加 |
| Flash 固有度 | 低（3 ランタイムとも §10.3.2 を正確に再現していなかった、プロンプト設計の問題）|

### 問題 2: 進捗管理シートのステータス「告知中」が enum 違反

| | 内容 |
|---|---|
| 期待 | §6.3 の enum 語彙のみ使用（未着手/ドラフト中/候補者承認待/詳細詰め/画像発注/広報準備/完了）|
| Gemini Flash 出力 | 「画像発注」または「告知中」と提案 |
| 原因 | Flash の確率的生成で類似語を生成しやすい |
| 対応 | **修正なし、Flash の限界として記録**（プロンプトでの明示は冗長と判断）|
| Flash 固有度 | 中〜高（Pro / Claude Code では enum 違反を起こしにくい）|

### 問題 3: 告知文の文体が GUIDELINES §3 と微妙に衝突

| | 内容 |
|---|---|
| 該当表現 | 「熱い思いを訴えます」「あなたの一票を託してください」 |
| GUIDELINES §3 の規定 | 「感情を強く刺激しすぎる表現を避ける」「落ち着いたトーン」 |
| 原因 | Flash の扇情表現生成傾向 |
| 対応 | **修正なし、Flash の限界として記録** |
| Flash 固有度 | 高（Pro / Claude Code は同じプロンプトでも扇情表現を抑える）|
