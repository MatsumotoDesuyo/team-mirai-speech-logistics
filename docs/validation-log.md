#### NG だった項目の対応方針

NG はゼロだが、minor improvement として次の余地あり:

| 項目 | 対応案 |
|---|---|
| Flash / Claude Code の「100m 独自数値」推論 | プロンプト禁止事項に「マニュアル・法令に明記のない距離・時間の数値を提示しない」を追加 |

| Claude Code の Read 省略 | 「ユーザーが進捗管理シート URL を渡したら、必ず内容を読み取って『現在の作業対象』『ステータス』を反映」を行動指針に追加 |

これらは Stage 3 合格判定には影響しないため、Stage 5 模擬日程 wet test 後の運用フィードバックを待ってから反映するかを判断する。

#### 性格の違い（運用上の含意）

- **Gemini Pro**: マニュアル原則順守、安全側 → サポーター大半向け（DESIGN §3 の幹に最適合）
- **Gemini Flash**: 実務的・具体的 → 時短重視のユーザー向け（独自推論やや多め）
- **Claude Code**: 法令最優先、批判的視点、代替案構築力 → エンジニア向け補完経路（DESIGN §3 の枝に最適合）
